# Keymap

The following list contains useful key bindings. The key `Cmdtrl` represents
`Cmd` on MacOS and `Ctrl` on all other systems. The key `Alt` represents
`Option` on MacOS and `Alt` on all other systems.

- `Alt+1`: [^MacOS] _(Browser, VSCode)_ Switch focus to first tab.
- `Alt+;`: _(Editor, Shell, Yazi)_ Move cursor right.
- `Alt+B`: _(Editor, Shell, Yazi)_ Jump backwards one word.
- `Alt+C`: _(Shell)_ Insert current working directory into the line.
- `Alt+E`: _(Shell)_ Edit line in default text editor.
- `Alt+F`: _(Editor, Shell, Yazi)_ Jump forward one word.
- `Alt+H`: _(Editor, Shell, Yazi)_ Open help menu.
- `Alt+J`: _(Editor, Shell, Yazi)_ Move cursor left.
- `Alt+K`: _(Editor)_ Move cursor down.
- `Alt+L`: _(Editor)_ Move cursor up.
- `Alt+O`: _(Fish)_ Open file under cursor in default pager.
- `Alt+P`: _(Shell)_ Append ` &| bat` to the line.
- `Alt+S`: _(Shell)_ Prepend `sudo ` to the line.
- `Alt+W`: _(Editor, Shell, Yazi)_ Delete text forwards one word.
- `Alt+X`: _(Fish, Nushell)_ Remove line from shell history interactively.
- `Alt+Z`: _(Shell)_ Undo line edit.
- `Alt+Down`: _(Editor)_ Swap line down.
- `Alt+Space`: [^Macos] _(Desktop)_ Open application launcher.
- `Alt+Up`: _(Editor)_ Swap line up.
- `Cmd+1`: [MacOS] _(Browser, VSCode)_ Switch focus to first tab.
- `Cmd+K`: [MacOS] _(Firefox)_ Switch focus to address bar.
- `Cmd+Space`: [MacOS] _(Desktop)_ Open application launcher.
- `Ctrl+.`: _(VSCode)_ Open code action.
- `Ctrl+[`:
  - _(Editor)_ Jump to previous location.
  - _(Fish)_ Jump to previous directory.
- `Ctrl+]`:
  - _(Editor)_ Jump to next location.
  - _(Fish)_ Jump to next directory.
- `Ctrl+/`: _(Editor)_ Toggle line comment.
- `Ctrl+\`: _(Editor)_ Split editor to the right.
- `Ctrl+A`: _(Browser, Editor, Shell, Yazi)_ Jump to the start of the line.
- `Cmdtrl+B`: _(Firefox)_ Toggle bookmarks sidebar.
- `Ctrl+D`: _(Zellij)_ Toggle interface lock.
- `Ctrl+E`: _(Browser, Editor, Shell, Yazi)_ Jump to the end of the line.
- `Ctrl+F`:
  - _(Shell)_ Search subdirectories for file.
  - _(VSCode)_ Open find bar.
- `Ctrl+G`: _(VSCode)_ Jump to line.
- `Ctrl+H`: _(VSCode)_ Open replace bar.
- `Ctrl+I`: _(Editor, Shell)_ Toggle completion menu.
- `Ctrl+K`:
  - [^Macos] _(Firefox)_ Switch focus to address bar.
  - _(Helix, Shell, Yazi)_ Clear text forwards to the end of the line.
- `Ctrl+L`:
  - _(Shell)_ Clear screen.
  - _(VSCode)_ Select line.
- `Ctrl+N`: _(Editor, Shell)_ Move to next selection in completion menu.
- `Ctrl+P`: _(Editor, Shell)_ Move to previous selection in completion menu.
- `Ctrl+R`: _(Shell)_ Search history for commands matching line.
- `Ctrl+S`: _(Helix)_ Save current location to jump list.
- `Ctrl+U`: _(Editor, Shell, Yazi)_ Clear text backwards to the start of the
  line.
- `Ctrl+V`:
  - _(Helix)_: Open file picker selection in vertical right split.
  - _(VSCode)_: Paste clipboard text.
- `Ctrl+W`: _(Editor, Shell, Yazi)_ Delete text backwards one word.
- `Ctrl+X`:
  - _(Shell)_ Copy line to system clipboard.
  - _(VSCode)_ Cut line.
- `Ctrl+Z`: _(Terminal)_ Send running process to background.
- `Ctrl+Down`: _(Editor)_ Add another cursor below.
- `Ctrl+Left`: _(Editor, Shell, Yazi)_ Jump backward one word boundary.
- `Ctrl+Right`: _(Editor, Shell, Yazi)_ Jump forward one word boundary.
- `Ctrl+Up`: _(Editor)_ Add another cursor above.
- `Ctrl+Tab`: _(Browser, VSCode, Wezterm)_ Switch focus right one tab.
- `Ctrl+Shift+.`: _(VSCode)_ Open breadcrumbs navigation.
- `Ctrl+Shift+[`: _(VSCode)_ Jump to previous version control change.
- `Ctrl+Shift+]`: _(VSCode)_ Jump to next version control change.
- `Ctrl+Shift+;`: _(Terminal, VSCode)_ Switch focus right one editor or terminal
  tab.
- `Ctrl+Shift+A`: _(VSCode)_ Toggle side panel.
- `Ctrl+Shift+B`: _(VSCode)_ Move terminal panel to bottom.
- `Ctrl+Shift+D`: _(VSCode, Zed)_ Open debug panel.
- `Ctrl+Shift+E`: _(VSCode)_ Open explorer panel.
- `Ctrl+Shift+F`: _(VSCode, Wezterm)_ Open find panel.
- `Ctrl+Shift+G`: _(VSCode)_ Open source control panel.
- `Ctrl+Shift+H`: _(VSCode)_ Open replace panel.
- `Ctrl+Shift+J`: _(Terminal, VSCode)_ Switch focus left one editor or terminal
  tab.
- `Ctrl+Shift+K`: _(VSCode, Wezterm)_ Switch focus left one terminal pane.
- `Ctrl+Shift+L`: _(VSCode, Wezterm)_ Switch focus right one terminal pane.
- `Ctrl+Shift+M`:
  - _(VSCode)_ Toggle maximization for integrated terminal.
  - _(Wezterm)_ Toggle fullscreen for pane.
- `Ctrl+Shift+N`:
  - _(VSCode)_ Create a new editor or terminal pane.
  - _(Wezterm)_ Create a new pane.
- `Ctrl+Shift+O`: _(VSCode)_ Open file search.
- `Ctrl+Shift+P`: _(VSCode)_ Open command palette.
- `Ctrl+Shift+R`: _(VSCode)_ Move terminal panel to right.
- `Ctrl+Shift+S`: _(VSCode)_ Switch focus between editor and terminal panel.
- `Ctrl+Shift+T`: _(Terminal, VSCode)_ Switch focus to terminal or create a new
  tab.
- `Ctrl+Shift+W`: _(VSCode, Wezterm)_ Close tab.
- `Ctrl+Shift+X`: _(VSCode)_ Toggle terminal panel.
- `Ctrl+Shift+Down`: _(Wezterm)_ Swap pane left.
- `Ctrl+Shift+Enter`: _(VSCode)_ Insert line above.
- `Ctrl+Shift+Left`:
  - _(VSCode)_ Swap editor tab left.
  - _(Wezterm)_ Swap tab left.
- `Ctrl+Shift+Right`:
  - _(VSCode)_ Swap editor tab right.
  - _(Wezterm)_ Swap tab right.
- `Ctrl+Shift+Tab`: _(Browser, VSCode, Wezterm)_ Switch focus left one tab.
- `Ctrl+Shift+Up`: _(Wezterm)_ Swap pane right.
- `Shift+Enter`: _(VSCode)_ Insert line below.
- `Shift+Left`: _(Shell, Yazi)_ Jump backward one full word.
- `Shift+Right`: _(Shell, Yazi)_ Jump forward one full word.
- `Shift+Alt+D`: _(Browser)_ Toggle VisBug developer tools.
- `Shift+Alt+Z`: _(Shell)_ Redo line edit.
- `Super+Escape`: _(Desktop)_ Lock screen.
- `Super+Tab`: _(Desktop)_ Switch focus to next application.
- `Super+Ctrl+1`: _(Desktop)_ Switch focus to desktop 1.
- `Super+Ctrl+Left`: _(Desktop)_ Throw window to desktop on the left.
- `Super+Ctrl+Right`: _(Desktop)_ Throw window to desktop on the right.
- `Super+Ctrl+Up`: _(Desktop)_ Open application overview.
- `Super+Ctrl+Shift+;`: _(Desktop)_ Switch focus to monitor on the right.
- `Super+Ctrl+Shift+J`: _(Desktop)_ Switch focus to monitor on the left.
- `Super+Ctrl+Shift+Left`: _(Desktop)_ Throw window to monitor on the left.
- `Super+Ctrl+Shift+Right`: _(Desktop)_ Throw window to monitor on the right.
- `Super+Shift+Left`: _(Desktop)_ Swap window left.
- `Super+Shift+Right`: _(Desktop)_ Swap window right.
- `Super+Shift+Tab`: _(Desktop)_ Switch focus to previous application.
- `Super+Shift+;`: _(Desktop)_ Switch focus right one window.
- `Super+Shift+F`: _(Desktop)_ Toggle floating for window.
- `Super+Shift+J`: _(Desktop)_ Switch focus left one window.
- `Super+Shift+M`: _(Desktop)_ Maximize window.

## Bitwig

The following key combinations are specific to Bitwig. You can find more Bitwig
shortcuts in the _Shortcuts_ section of the _Settings_ menu.

- `A`: Toggle automation panel.
- `B`: Insert from device browser.
- `D`: Toggle device panel.
- `E`: Toggle editor panel.
- `I`: Toggle inspector panel.
- `L`: Toggle clip/scene panel.
- `M`: Toggle mixer panel.
- `P`: Play or pause project.
- `Alt+H`: Show device help menu.
- `Alt+P`: Play project from start.
- `Alt+Space`: Play or pause project.
- `Ctrl+,`: Open settings menu.
- `Ctrl+D`: Duplicate selected region.
- `Ctrl+G`: Add new group.
- `Ctrl+J`: Consolidate selected region.
- `Ctrl+L`: Loop selected region.
- `Ctrl+R`: Rename item.
- `Ctrl+T`: Add new track.
- `Ctrl+Click`: Type specific value.
- `Shift+Down`: Transpose note selection down an octave.
- `Shift+Tab`: Toggle maximized editor view.
- `Shift+Up`: Transpose note selection up an octave.
- `Space`: Play or pause project.
- `Tab`: Switch focus between arranger mixer panels.

## Browsers

The following key combinations are specific to web browsers.

- `Space`: Scroll one screen down a webpage.
- `Cmd+Y`: [MacOS] _(Chrome)_ Open history manager.
- `Cmd+Alt+B`: [MacOS] _(Chrome)_ Open bookmarks manager.
- `Cmd+Alt+I`: [MacOS] Toggle developer tools.
- `Cmd+Alt+M`: [MacOS] Toggle responsive design mode.
- `Cmd+Shift+[`: [MacOS] _(Firefox)_ Switch focus left one tab.
- `Cmd+Shift+]`: [MacOS] _(Firefox)_ Switch focus right one tab.
- `Cmd+Shift+H`: [MacOS] _(Firefox)_ Toggle history sidebar.
- `Cmdtrl+LeftClick`: Open link in new tab.
- `Cmdtrl+[`: Navigate back a webpage in history.
- `Cmdtrl+]`: Navigate forward a webpage in history.
- `Cmdtrl+D`: Bookmark webpage.
- `Cmdtrl+F`: Open find bar.
- `Ctrl+H`:
  - [^MacOS] _(Firefox)_ Toggle history sidebar.
  - [^MacOS] _(Chrome)_ Open history manager.
- `Cmdtrl+T`: Create a new tab.
- `Cmdtrl+W`: Close tab.
- `Ctrl+F5`: _(Chrome)_ Switch focus to address bar.
- `Ctrl+Shift+I`: [^MacOS] Toggle developer tools.
- `Ctrl+Shift+M`: [^MacOS] Toggle responsive design mode.
- `Ctrl+Shift+O`: [^MacOS] _(Chrome)_ Open bookmarks manager.
- `Shift+Space`: Scroll one screen up a webpage.

## Helix

The following key combinations are specific to Helix.

- `O`: _(Normal, Select)_ Insert line below.
- `[ C`: Jump to previous comment.
- `] C`: Jump to next comment.
- `[ D`: Jump to previous diagnostic issue.
- `] D`: Jump to next diagnostic issue.
- `[ F`: Jump to previous function.
- `] F`: Jump to next function.
- `[ G`: Jump to previous version control change.
- `] G`: Jump to next version control change.
- `: 1`: Jump to line 1.
- `G D`: Jump to definition of symbol.
- `G J`: Jump to the start of the line.
- `G ;`: Jump to the end of the line.
- `G K`: Switch focus to previous buffer.
- `G L`: Switch focus to next buffer.
- `G R`: Open reference picker for object under cursor.
- `M I Character`: Select all text between nearest surrounding character pair.
- `Shift+O`: _(Normal, Select)_ Insert line above.
- `Space ?`: Open command palette.
- `Space A`: Open code action.
- `Space D`: Open diagnostic picker.
- `Space G`: Open version control changes picker.
- `Space J`: Open jump list picker.
- `Space S`: Open symbol picker.

## MuseScore

The following key combinations are specific to MuseScore.

- `N`: Toggle note input mode.
- `Ctrl+R`: Rewind song.

## Sonic Pi

The following key combinations are specific to Sonic Pi.

- `Alt+/`: Toggle line comment.
- `Alt+I`: Toggle help panel.
- `Alt+R`: Run code.
- `Alt+S`: Stop code.
- `Ctrl+I`: Show documentation for function under cursor.
- `Shift+Alt+[`: Switch focus to previous buffer.
- `Shift+Alt+]`: Switch focus to next buffer.

## VSCode

The following key combinations are specific to VSCode.

- `Ctrl+G D`: Jump to definition.
- `Ctrl+G Shift+D`: Jump to declaration.
- `Ctrl+G G`: Jump to next version control change.
- `Ctrl+G Shift+G`: Jump to previous version control change.
- `Ctrl+G L 1`: Jump to line 1.
- `Ctrl+G R`: Jump to reference.
- `Ctrl+G P`: Jump to next problem.
- `Ctrl+G Shift+P`: Jump to previous problem.
- `Ctrl+G T`: Jump to type definition.
- `Cmdtrl+K B`: Toggle bookmark on line.
- `Cmdtrl+K D`: Jump to definition of symbol.
- `Cmdtrl+K L`: Show bookmarks list.
- `Cmdtrl+K M`: Create labeled bookmark on line.
- `Cmdtrl+K F`: Close folder.
- `Cmdtrl+K P`: Peek definition.
- `Cmdtrl+K V`: Open markdown preview to the side.
- `Ctrl+P :+1`: Jump to line 1.

## Yazi

The following key combinations are specific to Yazi.

- `~`: Open help menu.
- `Z`: Change directory with Zoxide.
- `Shift+Y`: Undo yank selection.
- `Space`: Toggle current path in selection.
